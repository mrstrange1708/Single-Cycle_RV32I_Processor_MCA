## 2. Test Programs & Assembly Machine Code

- [x] `programs/test_all.s` & `programs/test_all.hex`: Full ISA verification suite (Program A).
  - Exercises all 10 RV32I instructions: ADD, SUB, AND, OR, XOR, ADDI, LW, SW, BEQ, BNE.
  - Verifies register initialization, arithmetic logic, memory store and load round-trip, forward BEQ branch taken (skipping `x9`), and forward BNE branch taken (skipping `x10`).
  - Terminal self-loop `beq x0, x0, 0` for safe halt.
- [x] `programs/sum_loop.s` & `programs/sum_loop.hex`: Iterative loop summation suite (Program B).
  - Computes $\sum_{i=1}^{5} i = 15$.
  - Exercises backward branching with negative two's-complement immediate (`fe311ce3` $\rightarrow$ $-8$ bytes), register accumulation, loop bound condition, and offset store `sw x1, 4(x0)`.
  - Terminates with `x1 = 15`, `x2 = 6`, `mem[1] = 15` after 19 instructions.
- [x] `programs/README_programs.md`: Comprehensive documentation detailing instruction mappings, cycle traces, and expected architectural state for both programs.
